# 第一阶段实现范围

日期：2026-10-28。本文件记录当前代码能实际运行的能力，作为后续迭代起点；目标功能详见 [SPEC](../SPEC.md)。

## 代码结构

| 位置 | 职责 |
| --- | --- |
| `src/agent_foundation/` | 从同级底座沿用的模型配置、DeerFlow 适配和 owner 隔离 Wiki；法律业务不写入该包。 |
| `src/legal_service/` | FastAPI、会话认证、SQLite、求取/消息/律师审核、文书模板、法考索引与导入 CLI。 |

## 运行流程

1. 用户注册或登录，服务端保存随机会话并发放 CSRF token。公开资料与已审核求取可匿名浏览；写操作要求登录，管理员 API 另需 `admin` 角色。
2. 求取提交后保持 `pending`，不会进入公开列表；管理员可通过、驳回。只有填入至少 10 字的核验依据并明确选择时才显示“平台核验”。报酬字段是意向金额，没有支付承诺或托管。
3. 提供者对公开求取建立一对一会话；只有求取方和该提供者可读取、发送该会话消息。
4. 律师申请人提交真实姓名、电话、身份证号、职业头像、身份证两面、执业证两页及执业信息后保持 `pending`；管理员须查看材料并填 HTTPS 执业公示来源，才能通过进入目录。身份证与执业证图片仅本人和管理员能读取，证号和电话不在公开目录返回；职业头像在认证通过后公开。
5. 文书场景库保存 44 份原创草稿蓝图和逐份 `intake_prompt`；在线模型仅提取用户明确给出的事实。缺少必填事实时追问，齐全后按蓝图生成；草稿可编辑、保存、复制，读取与修改均按所有者过滤。模板没有自动法律引用。
6. 来源目录存人工核对的官方入口元数据；每日后台任务另从国务院政策、司法部法考公告、最高法典型案例发布目录收录标题及原站链接，并记录同步状态。未配置模型时 Agent 返回来源导航；配置模型时沿用底座调用模型，提示词禁止把目录说成全文、禁止捏造法条。
7. 法考索引内置司法部 2013–2017 年可访问的历史目录链接。目录里有卷别与参考答案条目，但部分内链已失效；产品不存失效直达页。逐题题库默认空；CLI 要求权利依据和 HTTPS 证据 URL 才可导入 JSONL。导入后搜索 API 支持题干关键词、年份和科目。
8. AI 模拟法考使用 `MODEL_CONFIG_JSON` 指定的在线模型逐题生成原创练习，服务端校验四个选项、答案数量和解析。题目答案存于 SQLite，未作答前不返回。单选 1 分、多选 2 分，整题判对才得分；用户可恢复练习并查看本组成绩，每日最多生成 30 题。本项目的启动脚本不运行 Ollama。
9. 文书区以场景检索和对话替代字段表单；Word、Excel、PPT 文件从已保存蓝图和对话事实生成，可下载或打印。三个公开空白 Office 模板仍可下载。旧版自由起草 API 保留兼容，但主页面不展示表单式入口。Excel 以文本保存类似公式的外部输入，避免执行公式。
10. 登录后的头像菜单进入个人信息管理；管理员额外可进入单一后台，处理求取和律师审核、查看站内消息、管理用户角色、添加或归档对话式文书模板，并手动检查官方目录。用户表有邮箱唯一索引、角色与创建时间、昵称、电话索引，管理列表分页。

## 当前边界

- 目前没有法条全文或历史版本库、案例全文索引、条款级修订比对、地区化办事清单、企业股东信息镜像；官方更新只监测标题和链接。企业搜索返回需去官方实名核验的状态，不会虚构结果。Agent 的答复不能作为律师对个案的正式意见。
- 目前没有支付、托管、退款或律师预约与委托流程；信息求取金额仅作展示和线下协商参考。
- 律师案例仅为申请者填写的匿名摘要；尚无客户授权材料审核、公开答疑记录或服务完成统计。
- 求取审核和律师核验是人工判断；关键词拦截只是初筛，尚无举报、申诉、复核有效期、附件交付与自动风控。
- SQLite 和本地会话适合单实例验证。正式互联网部署需迁移、HTTPS 安全 Cookie、限流、审计留存策略、加密/备份、内容治理与授权数据接入。导入器只校验权利证据的格式，不自动核实权利归属。
- Office 文件生成提供可编辑的起草框架，不是完整的在线 Word/Excel/PPT 编辑器。AI 生成的合同、表格和简报尚无律师逐份审校；签署、提交或打印前应核对事实、格式与适用法规。当前文件内容存储在本地 SQLite，正式部署需补充加密与删除期限。

2. 为案例、政务、企业公示接入得到许可的接口或人工维护结构化条目，并为每条数据记录来源、访问时间、地域、更新频率与失效处理。
3. 增加问答评测集、律师复核、举报与申诉流程；完成密聊和材料生命周期设计。
4. 在有明确题库授权后导入逐题正文，加入学科、知识点、答案版本与纠错流程；2018 年后回忆题单独标注为非官方。
