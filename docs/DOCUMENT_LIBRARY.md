# 文书场景库

当前共 44 份场景蓝图。运行产品从 `src/legal_service/document_scenarios.py` 读取这些内容。每份蓝图包含用途、字段分级、原创建议正文、来源参考链接和完整 `intake_prompt`；用户只需在聊天中说出事实。

## 信息提问方式

每份 `intake_prompt` 都要求 Agent：只依据用户明确提供的事实填写；必填项不齐则追问；非常建议项尽量一次询问，用户不提供则标记【待确认】；选填项仅在相关时询问；不主动索取无关身份证号、银行卡号；生成后提醒核对事实与现行规则。

例如房屋租赁合同的必填信息是出租人、承租人、房屋地址、租期和租金；押金、费用承担、交付情况非常建议补充；维修和提前解除约定为选填。用户可以用一段自然语言回答，Agent 会提取并填入草稿。
